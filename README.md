## ⚙️ Using the application

Once the application opens, you control your AI connections through a simple dashboard. 

### Setting your keys
You need API keys from the AI providers you want to use. These keys act as passwords for your accounts. Input these keys into the Settings menu inside Switchboard once. The software saves these locally on your hard drive, meaning no third party gains access to your credentials.

### Viewing your history
The application records the path of every request. If you want to know why a specific AI model provided a response, click the History tab. You will see a log detailing which provider handled the task and why the system chose that path. This transparency helps you identify which providers offer the best value for your specific needs.

### Managing providers
You can toggle different providers on or off. If you prefer not to use a specific service, simply disable it in the provider list. The router will then only choose from your enabled options. This manual control gives you flexibility while maintaining the safety of automatic fallback.

## 🛡 Security and privacy

Privacy remains a priority. Switchboard keeps your logs and configuration files entirely on your personal machine. No central server monitors your activity. Because the tool uses local storage, you maintain full ownership of your request history. 

## ❓ Frequently asked questions

**Does the software cost money to run?**
The software is free to use. However, you may need a paid subscription or credits with individual AI providers to use their services through Switchboard.

**What happens if my internet disconnects?**
The software requires a connection to reach the AI providers. If your internet fails, the application will queue your requests and attempt to reconnect automatically once the signal returns.

**Can I use this for business?**
Yes. The software handles AI requests for personal or professional tasks. Because it logs every interaction, it serves as a great tool for tracking usage across different projects.

**Does it slow down my computer?**
The software runs as a light background process. It consumes minimal memory and only requires resources when you send an active request to an AI provider.

**How do I update the software?**
When a new version becomes available, the application notifies you. Click the link in the notification to download and install the update.

## 🔧 Troubleshooting common issues

If the application fails to connect, verify your internet status first. Next, check that your API keys are entered correctly in the settings menu. Often, a key expires or reaches a usage limit, which causes connection failures. If you see an error, the History tab provides a specific message explaining what went wrong. You can copy these details if you need further help.
